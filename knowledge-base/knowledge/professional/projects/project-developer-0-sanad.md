# Sanad

Category: Web App

Company: AgileTz

Role: Frontend Web Dev

Type: Public / Governmental

Location: Jordan

## Overview

Sanad is Jordan’s national gateway to digital government services. Built the frontend from scratch and maintained it as the only frontend developer.

## Contributions and details

- Delivered a responsive, modular frontend interface supporting various ministries and services.

- Maintained accessibility, performance, and UX consistency across a growing number of services.

- Collaborated closely with backend and DevOps teams to ensure seamless API integrations.

- Contributed to UI/UX design decisions with the PM for maximum citizen engagement.

- Technically the product was ready for usage, weren't published for non-technical issues.
