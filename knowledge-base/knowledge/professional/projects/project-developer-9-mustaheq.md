# Mustaheq

Category: Web App

Company: Shai

Role: Full-Stack Dev

Type: Public / Governmental

Location: Saudi Arabia

## Overview

A government-backed unified platform enabling non-profit organizations in Saudi Arabia to coordinate, streamline operations, and manage beneficiaries. Led the project end-to-end as full-stack developer and tech lead.

## Contributions and details

- Designed and built the platform architecture from scratch using NestJS (backend) and ReactJS (frontend).

- Developed modules for beneficiary management, eligibility tracking, and coordination across multiple government bodies.

- Implemented role-based access for government officials, NGOs, and auditors with strict data permissions.

- Led a small cross-functional team and collaborated closely with product management and design.

- Ensured compliance with Saudi government digital infrastructure standards and data security requirements.

## Technologies

React.Js, CSS, Bootstrap, Node.Js, MicroServices, Nest.Js, TypeScript, JSON, REST API
