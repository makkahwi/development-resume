# Semesteer

Category: Web App

Company: AlembicSoft

Role: Full-Stack Dev

Type: Education

Location: Jordan

## Overview

A full-featured School Information System (SIS) SaaS platform. Superheaded the project from concept to deployment — including client interviews, UX/UI design, architecture, development, and production delivery.

## Contributions and details

- Designed and implemented a multi-tenant architecture allowing each school to have isolated data environments.

- Built core modules including student profiles, course management, attendance, fees, results, and parent portals.

- Developed role-based access control and school-specific branding capabilities.

- Integrated PDF generation, notifications, analytics dashboards, and support for both English and Arabic languages.

- Optimized for AWS deployment with CI/CD, Docker, and secure configuration.
