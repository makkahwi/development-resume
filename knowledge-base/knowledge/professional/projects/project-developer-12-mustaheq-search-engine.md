# Mustaheq Search-Engine

Category: Web App

Company: Shai

Role: Full-Stack Dev

Type: Public / Governmental

Location: Saudi Arabia

## Overview

A specialized under-construction Arabic search engine to help individuals find relevant Saudi charities & societies, especially those using the Mustaheq portal.

## Contributions and details

- It was sort of my own idea to come up with, approved by owner.

- Aimed at simplifying access to aid for recipients and boosting visibility for subscribing charities.

- Public profiles were indexed with essential contact info, eligibility, and activity areas.

- Powered by ElasticSearch and optimized with advanced database indexing for fast and accurate search.

- Included admin tools to manage searchable metadata and optimize search relevance.

## Technologies

Vite, CSS, TailwindCSS, Node.Js, ElasticSearch, Nest.Js, TypeScript, JSON, REST API
